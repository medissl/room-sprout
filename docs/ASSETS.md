# Original visual assets

All six photographic assets were generated with the built-in image-generation tool for this project. The optimized JPGs live in `assets/`. The source PNGs remain in the Codex generated-images folder. No retailer photography was copied. These are concepts, not real catalog listings.

- `assets/room-editorial.jpg`: small renter bedroom, sage wall and throw, cream linen, warm wood, soft afternoon light, eye-level 28mm doorway composition, attainable lived-in editorial photography, no people/text/logos.
- `assets/reading-corner.jpg`: olive lounge chair, oatmeal cushion, walnut table, pleated lamp, potted plant, natural side light in a small apartment, tactile editorial photography, no people/text/logos.

Product prompt template used for each asset:

> Photorealistic editorial product photograph for RoomSprout earthy interior styling app. Square image. [SUBJECT]. The only object rests on a matte pale cream studio surface with matching cream background, soft natural side light from the upper left, subtle realistic shadow, rich tactile material detail, understated premium independent homewares catalog art direction, warm gentle light, attainable real product, object fully visible centered occupying 65 percent of frame, plenty of breathing room. No text, no brand, no logo, no people, no extra objects, no border, no collage. This is a product concept photo, not a specific brand item.

Subjects:

- `assets/lamp.jpg`: A single warm brown ceramic bedside table lamp with an oatmeal cream pleated linen shade, turned off.
- `assets/throw.jpg`: A single neatly loosely folded sage green cotton throw blanket with a soft fringe and visible woven texture.
- `assets/vase.jpg`: A single sculptural small warm cream textured ceramic vase with an organic rounded shape and short neck, empty.
- `assets/cushion.jpg`: A single square oatmeal linen cushion, softly plump, with fine warm brown piping.

The app icon is a project-authored botanical mark. The interface uses explicit text controls instead of a generic icon library. Fonts use the DM Sans package and its bundled license. Keep the upstream Expo template license notice.
